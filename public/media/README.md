# Catalogo de recursos graficos

Todos los recursos visuales de la pagina se guardan en esta carpeta.

## Estructura

- `brand/`: logos y variantes de identidad visual de AP.
- `clients/`: logos de clientes y archivos fuente pendientes de identificar.
- `events/`: fotografias de eventos, agrupadas por nombre y secuencia.
- `institutional/`: imagenes editoriales para hero, firma, servicios y referencias.
- `team/`: fotografias del equipo nombradas por persona.

## Convenciones

- Usar nombres en minusculas y palabras separadas con guion.
- Numerar secuencias con dos digitos: `evento-01.jpeg`, `evento-02.jpeg`.
- Mantener el nombre de la persona, cliente o evento cuando este confirmado.
- Usar el prefijo `unidentified-` para archivos cuyo nombre definitivo este pendiente.
- Guardar documentos descargables fuera de esta carpeta, en `public/portfolio/`.

## Recursos institucionales activos

- `brand/ap-logo-header.png`
- `brand/ap-logo-primary.png`
- `institutional/hero-office.jpg`
- `institutional/about-office.jpg`
- `institutional/services-consulting.jpg`

Los archivos `institutional/event-reference-*.jpg` se conservan como referencias visuales y actualmente no se muestran en la pagina.
